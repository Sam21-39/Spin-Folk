Interaction spec · v2

How it moves and responds

Restrained party feel: every motion confirms something real (a spin, a result, a deletion). Nothing loops, nothing flashes. Reduce Motion keeps every outcome and only shortens the theatre.

Flick to spinGame · Flutter

Drag starts on the bottle (light haptic on grab). Release with angular speed ≥ 3 rad/s fires the same SpinRequested as the button. Flick only starts the spin: the outcome is chosen by the app, and duration/turns follow the normal spin plan. Slow release snaps the bottle back. Disabled while spinning.

Reveal choreographyGame · Flutter

Stop → medium haptic → selected seats pulse twice → role cards rise 16 px with 60 ms stagger (taker first) → announcement. Reduce Motion: crossfade, no pulse, same order.

Hub → game hand-offNavigation

Home’s mini dial and the game dial share a hero transition (420 ms, ease-out). Resume and Play again land on Ready with the bottle at its last pose, so the circle sees continuity.

Quick counts + wheelSetup · native

Chips 4/6/8/10/12 set the native wheel instantly (wheel animates to value, selection haptic). The live seat preview redraws with the count so the group can sit before starting.

SheetsNative-feel

Round log and Session sheets use medium + large detents, grabber, swipe-down to dismiss. They pause nothing — the game state is unchanged underneath.

Swipe to deleteHistory

Trailing swipe reveals coral Delete (96 pt). Past 60% width: rigid haptic, full swipe deletes. Row collapses 250 ms. VoiceOver: custom action “Delete game”.

Undo instead of nagHistory

Single delete via swipe needs no dialog: it shows an Undo toast for 5 s with a countdown ring. Delete from detail and Clear all ask once (destructive, bigger blast radius) and still offer Undo. Data is soft-deleted, then purged when the toast ends or the app backgrounds.

End → summarySession

End Session confirms once, then shows a short summary (counts, most-picked) and offers Play again with the same circle. The game is saved to History; the Live Activity ends with “Session ended · 12 rounds”.

Haptic mapSystem

Picker/chips: selection. Grab bottle: light. Stop: medium (once). Swipe threshold: rigid. Delete: none extra. Errors: notification .error. Nothing else vibrates.
